# Edublossom Solutions — Free Website

## How to use
1. Open `index.html` in a browser to preview the site.
2. Replace `hello@edublossomsolutions.com` in `index.html` with your real business email.
3. Upload `index.html` to any static/free web host.

## Free hosting options
- GitHub Pages
- Netlify
- Cloudflare Pages

The site is a single responsive HTML file and needs no paid software, database, or hosting server.
